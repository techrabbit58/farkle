# A Function For Scoring The Farkle Game
This is a programming practice in python,
inspired by [the "Greed" coding kata](https://codingdojo.org/kata/Greed/).

The "Greed" dice rolling game is also known as "Farkle".
A [description of the Farkle game](https://en.wikipedia.org/wiki/Farkle)
can be found in Wikipedia.
